# Touch Loop — پروژه آزمایشی ماکرو اندروید

## این نسخه چه می‌کند؟
- پنل شناور با Record، Stop و Play loop
- ضبط رویدادهای قابل‌دسترسی از نوع کلیک و اسکرول در برنامه‌های دیگر
- ذخیره محلی ماکرو در SharedPreferences
- بازپخش تکراری تا فشردن Stop
- اجرای لمس‌ها با AccessibilityService و dispatchGesture

## محدودیت‌های مهم
این یک MVP آزمایشی است، نه ضبط‌کننده کامل لمس خام:
- تایپ متن، کلیدهای صفحه‌کلید، لمس‌های خالی صفحه، کشیدن آزاد انگشت و ژست‌های چندلمسی ضبط نمی‌شوند.
- رویداد اسکرول به یک حرکت عمودی تقریبی تبدیل می‌شود.
- برخی برنامه‌ها، صفحات امن، محتوای بازی‌ها و نسخه‌های مختلف اندروید ممکن است با این روش سازگار نباشند.
- مختصات بازپخش به اندازه صفحه و چیدمان برنامه وابسته‌اند.
- برای استفاده مسئولانه، ماکرو را ابتدا در محیط کم‌خطر آزمایش کنید. از آن برای دور زدن محدودیت‌های برنامه‌ها، کلیک تقلبی یا اقدامات مالی/حساس استفاده نکنید.
- هیچ داده‌ای به سرور ارسال نمی‌شود؛ رویدادها روی دستگاه ذخیره می‌شوند. این نسخه متن تایپ‌شده یا رمزها را ضبط نمی‌کند.

## باز کردن پروژه
1. Android Studio را نصب کنید.
2. پوشه `TouchLoopAndroid` را از طریق **Open** باز کنید.
3. اگر Android SDK 35 نصب نیست، از SDK Manager نصبش کنید.
4. اجازه بدهید Gradle Sync انجام شود.
5. گوشی را با USB وصل کنید و USB debugging را فعال کنید، یا از شبیه‌ساز استفاده کنید.
6. از Run برنامه را نصب کنید.
7. داخل برنامه روی «فعال‌سازی Accessibility» بزنید و سرویس Touch Loop را فعال کنید.
8. به برنامه موردنظر بروید. پنل شناور را برای ضبط، توقف و تکرار استفاده کنید.

## نیازمندی‌های ساخت
- Android Studio جدید
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.3

این فایل‌ها سورس پروژه هستند؛ APK کامپایل‌شده همراه ZIP نیست.

## ساخت APK به‌صورت آنلاین، بدون نصب Android Studio

این مخزن یک گردش‌کار GitHub Actions دارد که با اجرای آن، APK آزمایشی ساخته و به‌صورت Artifact قابل دریافت می‌شود.

1. در GitHub وارد حساب خود شوید و یک مخزن جدید بسازید (مثلاً `TouchLoopAndroid`).
2. فایل ZIP پروژه را روی کامپیوتر از حالت فشرده خارج کنید.
3. محتویات پوشه `TouchLoopAndroid` را به مخزن GitHub آپلود کنید؛ پوشه `.github/workflows` را هم حتماً نگه دارید. ساختار مخزن باید مستقیماً شامل `app/`, `build.gradle.kts`, `settings.gradle.kts` و `.github/` باشد.
4. پس از ثبت فایل‌ها، زبانه **Actions** را باز کنید و گردش‌کار **Build Touch Loop APK** را انتخاب کنید. اگر اجرا نشده، روی **Run workflow** بزنید.
5. وقتی اجرا سبز و موفق شد، در پایین صفحه اجرای workflow بخش **Artifacts** را پیدا کنید و `TouchLoop-debug-apk` را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید.

### محدودیت‌های نسخه فعلی
این گردش‌کار فقط سورس فعلی را کامپایل می‌کند؛ به‌خودی‌خود قابلیت‌های جدید اضافه نمی‌کند. نسخه فعلی برای کلیک‌های قابل‌دسترسی و رویدادهای اسکرول تقریبی است و هنوز تایپ متن و ضبط کامل ژست‌های آزاد را پیاده‌سازی نکرده است. APK خروجی، نسخه آزمایشی و امضانشده برای انتشار عمومی است؛ پیش از استفاده واقعی باید روی گوشی آزمایش شود.
